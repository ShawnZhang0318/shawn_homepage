# 个人数字档案室 Three.js 灰盒

这是独立的真实尺度 Three.js 房间预览，用于检查空间比例、主要物件位置、窗洞和遮挡。场景只使用简单几何体和占位画面，不含真实个人资料、正式贴图或细模。

## 启动

复用 `outputs/node_modules/three`，无需安装依赖或改动项目 `package.json`。从 `outputs` 目录启动静态服务器：

```powershell
cd outputs
python -m http.server 8000
```

浏览器打开 <http://localhost:8000/room-greybox/>。也可将 `python` 替换为 `py`。不要直接双击 `index.html`，ES modules 需要 HTTP 服务。

## 控制

- 鼠标左键拖动：旋转相机；滚轮：缩放；右键拖动：平移。
- 手机/触摸设备可单指旋转、双指缩放和平移。
- 顶部按钮切换正面、侧面、俯视和默认视角；拖动场景可自由探索。
- 点击几何体或在底部对象选择器选择对象，可查看其 ID 与规格坐标 AABB。
- 点击桌灯或落地灯分别平滑切换对应照明。

## 坐标和范围

房间净空为 6.0 × 4.8 × 2.8 m。数据使用规格坐标 `X=向右、Y=从主墙向观看者、Z=向上`；Three.js 将其映射为世界 `(X, Z, Y)`，以保持渲染世界的 Y 轴向上。主墙实体在规格 `Y=-0.12..0`；右墙在 `X=6.00..6.12`，窗洞留空，不生成墙碰撞。正面、侧面和俯视预设都以该坐标系定位。

场景按 `docs/ROOM_DESIGN_SPEC.md` 与 `docs/OBJECT_INTERACTION_MAP.md` 的外框搭建：

- 工程工作站：2×2 墙屏、笔记本左侧的桌面主显示器、笔记本、桌下主机、键盘和鼠标。
- 桌面资料：Hobby 卡册、WORK 纸、名片和单个 CV 档案袋。
- 奖项柜及通用奖杯/奖牌占位；独立机械臂台和折叠姿态机械臂。
- 独立桌灯与落地灯、右侧墙夜景开口和通用城市轮廓；蓝白围巾占位在主墙约 `X=1.95–2.73 m / Z=2.12–2.30 m`，来自已批准正立面图的像素比例换算。
- 第 11 项媒体边桌、CRT、下层 VCR、独立 TAPE-01–04 占位。

媒体边桌以开放框架表示；VCR 下方承托板与其底面按规格对齐。实体表面只使用功能类别颜色；屏幕为无个人事实的通用占位图。房间、桌面与 2×2 墙屏范围定义在 `room.js` 的 `SPEC` 常量中，其他独立物件在各自的创建段落中标明规格边界。

## 灰盒边界

该预览不实现正式内容 CMS、CV/PDF、知识星图应用详情、VHS 解码/音视频、物理模拟、材质烘焙或最终灯光。笔记本只显示通用知识图谱概念画面；点击对象用于检查 ID 与坐标，不代表正式内容导航实现。落地灯位置按当前规格表采用 X0.62–0.92 / Y0.95–1.25。蓝白围巾采用批准正立面示意的近似坐标，具体尺寸允许灰盒阶段按视线检查微调。
