# Shawn Homepage

张艺桐（Yitong Zhang）的中英双语个人主页，使用原生 HTML、CSS 和 JavaScript 编写，无需构建工具。

## 本地预览

在项目根目录运行：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 主要文件

- `index.html`：主页
- `research.html`、`projects.html`、`experience.html`：研究、项目与经历
- `CV/`：简历页面及 PDF
- `styles.css`、`script.js`：样式与交互
- `assets/`：图片资源

## GitHub Pages

在仓库 **Settings → Pages** 中选择 **Deploy from a branch**，设置分支为 `main`、目录为 `/ (root)` 即可发布。
